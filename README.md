# camillabianchi.github.io

This is the source for my personal academic website: https://camillabianchi.github.io

I'm a PhD candidate in Economics at LUISS Guido Carli University in Rome, working on applied micro, labor, family and public economics. I use this site to keep my research, teaching and CV in one place.

## What's on the site

- **Home**: a short bio, my research interests and contact details
- **Research**: my work in progress, policy writing, and the conferences and seminars where I've presented
- **Teaching**: the courses I've been a teaching assistant for at LUISS
- **CV**: a PDF of my CV

## How it's built

It's a simple static site built with Jekyll and hosted on GitHub Pages. Each page is a plain Markdown file (`index.md`, `research.md`, `teaching.md`), the layout is in `_layouts/default.html` and the styling is in `assets/css/style.css`. My CV lives in `files/` and my photo in `images/`. Any change pushed to `main` goes live automatically.
